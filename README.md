# Real time quality monitoring in production using SCADA systems at HLL

## 📝 Description
This project focuses on evaluating the impact of implementing a real-time quality monitoring system using SCADA in the production line at HLL. We analyzed the system performance before and after implementation by comparing parameters such as rejection rate, warning levels, and process efficiency. Data on current and voltage during testing were collected and studied to identify variations affecting product quality. After implementation, improvements in monitoring, accuracy, and decision-making were observed. The comparison clearly shows a reduction in unnecessary rejections and better process control. This study highlights how SCADA enhances productivity, consistency, and overall quality in manufacturing operations.
